# Contributing to thisistheway.to

Thank you for your interest in contributing!

## How to Contribute

This project uses **pull requests only** — there is no issue tracker.

### Submitting Changes

1. Fork the repository
2. Create a branch for your changes
3. Make your changes with clear, semantic commits
4. Open a pull request with a description of what you changed and why

### Pull Request Guidelines

- Keep changes focused and atomic
- Write clear commit messages
- Ensure the build passes (`cd site && bun run build`)
- Test locally before submitting (`cd site && bun run dev`)

## Development Setup

```bash
cd site
bun install
bun run dev
```
